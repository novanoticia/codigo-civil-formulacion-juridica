# plantilla-caso.md — Formato de entrada para el skill

Esta plantilla es **orientativa**, no obligatoria. El skill puede procesar casos redactados en prosa libre siempre que contengan información suficiente. Cuanto más se acerque la entrada a esta estructura, más limpio será el paso 1 (estructuración).

## Encabezado

- **Identificador del caso**: usar pseudónimo o iniciales no reconocibles (p. ej., "Cliente A", "C.M., 47 años").
- **Confirmación de pseudonimización**: una línea afirmando que se han retirado identificadores directos (nombres, DNI/NIE, dirección, datos bancarios, números de finca, denominación social exacta de las partes, número de procedimiento).
- **Marco profesional**: rol del jurista que envía el caso (abogado en ejercicio, asesor jurídico, estudiante avanzado bajo supervisión) y contexto (despacho generalista, especialista, clínica jurídica universitaria).

## Cuerpo del caso

### Identificación del supuesto y fase
Tipo de actuación profesional: consulta extrajudicial, fase preprocesal, procedimiento ya iniciado (especificar tipo: ordinario, verbal, monitorio, especial, ejecución, recurso). Si hay procedimiento, fase actual.

### Partes
Rol procesal o material de cada una. Condición jurídica relevante: consumidor, empresario, profesional, persona con medidas de apoyo (Ley 8/2021), menor, administración pública. Vecindad civil cuando se conozca o pueda inferirse del caso (común, foral —Cataluña, Aragón, Navarra, País Vasco, Galicia, Baleares—).

### Hechos relevantes
En orden cronológico, con marcas temporales relativas ("hace 14 meses", "durante el primer trimestre de 2024"). Distinguir hechos ya acreditados documentalmente de hechos referidos por el cliente sin acreditación.

### Pretensión / encargo profesional
Qué busca el cliente o cuál es el encargo: cumplimiento, resolución contractual, indemnización, declarativa de nulidad, modificación de medidas, declaración de herederos, etc.

### Documentación disponible
Lista de documentos en poder del jurista o del cliente, con valor probatorio prima facie cuando se conozca (contrato firmado, burofax con acuse, parte médico, certificado registral, etc.).

### Posición conocida o esperable de la contraparte
Alegaciones ya formuladas, requerimientos respondidos, líneas previsibles de oposición. Si hay procedimiento abierto, contenido conocido de los escritos contrarios.

### Antecedentes
Litigios previos entre las mismas partes, requerimientos extrajudiciales remitidos o recibidos, intentos de mediación o conciliación, transacciones parciales, comunicaciones relevantes.

### Plazos relevantes
Fechas o referencias temporales relevantes para prescripción y caducidad. Actos interruptivos documentados (burofaxes, reclamaciones, demandas previas archivadas, etc.).

### Hechos pendientes de acreditar
Hechos relevantes para la calificación cuya prueba aún no consta o no es sólida.

### Datos pendientes de recabar
Lo que el jurista ya sabe que falta y planea pedir o investigar.

---

## Lo que NO debe incluir el caso

- Nombres reales, DNI/NIE, dirección, teléfono, correo electrónico, datos bancarios.
- Denominación social exacta de empresas si son identificables (usar "cadena nacional de supermercados", "constructora local", etc.).
- Número de procedimiento judicial concreto, juzgado y partido judicial concretos si juntos identifican el asunto.
- Fechas exactas de nacimiento, matrimonio, fallecimiento, hechos relevantes (usar aproximaciones: "hace 14 meses", "comienzos de 2024").
- Número de finca registral, número de cuenta, IBAN, números de póliza concretos.
- Datos de terceros (testigos, peritos por nombre, profesionales intervinientes) que permitan identificar el caso indirectamente.
- Documentos adjuntos sin pseudonimizar (fotografías, escritos con membrete, contratos con firma).
- Información cubierta por secreto profesional sobre el cliente sin su consentimiento expreso para uso en consulta jurídica con asistencia de IA.

## Comprobación rápida antes de enviar

- [ ] El caso está pseudonimizado: nombres, identificadores directos, denominaciones sociales y números de procedimiento sustituidos.
- [ ] El usuario que envía el caso es jurista habilitado o estudiante avanzado bajo supervisión.
- [ ] No hay datos identificables directos ni indirectos.
- [ ] Si hay riesgo de pérdida de plazo inminente (días o semanas), el jurista lo señala expresamente; este flujo no sustituye la diligencia profesional.
- [ ] Si concurren elementos de detección inicial (foral, consumidor, persona con medidas de apoyo, menor), se mencionan al describir las partes para que el flujo los recoja en los avisos iniciales.
